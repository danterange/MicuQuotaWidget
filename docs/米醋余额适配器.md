# 米醋余额适配器

## 来源与边界

适配器参考公开的 MicuCodeLine / MicuSubCodeLine 源码，不启动其 CLI。这样避免解析 ANSI status line、进入 TUI、自动安装副作用，以及把 Claude 配置文件当作小组件接口。

## 支持的只读模式

| 模式 | 固定 HTTPS 主机 | 查询顺序 | 余额计算 |
| --- | --- | --- | --- |
| Micu API | `https://www.micuapi.ai/` | `/api/user/self`，不可解析时 fallback 到 billing | `quota - used_quota` 按 500000 quota/USD 换算；billing 使用 `hard_limit_usd - total_usage / 100` |
| Micu Subscription | `https://sub.micuapi.ai/` | `/v1/usage` | 响应中的 `balance` |

上述字段和倍率来自公开源码行为，可能随服务端变化。Profile → billing fallback 只适用于 401/403（profile 需要 session）、404/405（profile 不支持）或 profile JSON/字段无法解析；429、5xx、重定向、超时和取消不会触发额外 billing 请求，以免每 10 秒放大服务端故障。任何失败都不应把“0”伪装成余额；UI 保留上次成功结果并显示可恢复的错误。

## 安全要求

- 使用 `Authorization: Bearer`，绝不写入请求头、Key、原始响应或账户标识到日志。
- Key 通过 Windows Credential Manager 保存，设置文件只存无敏感的 endpoint mode。
- 只允许固定 HTTPS 主机，拒绝 localhost、私网、重定向脚本和用户任意 endpoint。
- 每 10 秒最多一个在途查询，单次 HTTP headers、body 与 JSON 解析合计超时 5 秒，窗口关闭时取消。HTTP client 禁止自动重定向。

## 真实验证

在实现或发布前，必须用用户授权的测试 Key 核实 endpoint、HTTP 状态、响应 schema、币种和单位；验证记录不得包含 Key、完整 URL 参数、账户身份或原始响应。
