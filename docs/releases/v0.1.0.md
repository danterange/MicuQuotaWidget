# v0.1.0 发布说明

## 功能

- 初始 WPF Micu 余额桌面小组件。
- 默认 10 秒安全轮询、置顶切换、设置窗口和 Windows Credential Manager 存储。
- Core unit/integration test、WPF UI smoke test、截图门禁和自动化脚本。

## 验证

- 运行 `scripts/Invoke-QualityGate.ps1`。
- 手工查看由 UI smoke test 生成的演示截图。

## 兼容性

- Windows 10/11 x64，.NET 8 Desktop Runtime。
- Micu 接口字段与倍率来自公开源码观察，真实账号须用授权测试 Key 验证。

## 升级

- 首次使用请在设置中选择账户类型并保存仅用于余额查询的 API Key；Key 保存于当前 Windows 用户的 Credential Manager。
- 从后续版本升级时保留原有设置即可；如果查询方式或接口字段变化，先阅读 `docs/米醋余额适配器.md`。

## SHA-256

- 远程发布后以对应 GitHub Release 附件 `SHA256SUMS.txt` 为唯一校验来源；当前本地初始化版本尚未绑定远程 Release。
