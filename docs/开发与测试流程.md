# 开发与测试流程

## 本地质量门禁

每次修改后执行：

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\scripts\Invoke-QualityGate.ps1
```

门禁按顺序执行：restore、format check、Release build、Core unit test、mock HTTP integration test、WPF UI smoke test、publish smoke check。任一步失败后停止，不提交、不推送、不发版。

## 测试层级

| 层级 | 项目/脚本 | 覆盖范围 |
| --- | --- | --- |
| Unit test | `MicuQuotaWidget.Core.Tests` | URL 白名单、额度换算、异常边界 |
| Integration test | `MicuQuotaWidget.Core.Tests` | Mock `HttpMessageHandler` 下的 self → billing fallback 与 Subscription 路径 |
| UI test | `MicuQuotaWidget.UiTests` | STA 创建窗口、固定尺寸、关键控件、AutomationProperties、默认置顶 |
| UI screenshot | `scripts/Test-Ui.ps1` | 演示数据截图和人工视觉验收入口 |

真实账户接口验证只在用户明确授权且提供可撤销测试 Key 后执行；默认测试严禁读取本机 Claude、Codex 或浏览器配置。
